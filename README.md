# 🏥 Hospital Network Design Project

## 📌 Project Overview

This project demonstrates the design and implementation of a **secure and efficient hospital network** using Cisco Packet Tracer. The network is designed to provide reliable communication between different hospital departments while maintaining security and controlled access.

## 🎯 Objectives

* Design a hierarchical hospital network.
* Separate departments using **VLANs**.
* Enable communication between VLANs using **SVI Inter-VLAN Routing**.
* Configure **DHCP** for automatic IP address allocation.
* Implement **Static IPv4 addressing** for important devices.
* Improve network security using **ACLs and Port Security**.
* Configure **SSH** for secure remote device management.
* Implement **NAT Overload (PAT)** for Internet access.
* Establish a **Site-to-Site IPsec VPN**.
* Configure **WLAN** connectivity.
* Test end-to-end connectivity and security policies.

## 🌐 Network Features

### VLANs

Different hospital departments are separated using VLANs to improve network organization and security.

### Inter-VLAN Routing

SVI-based routing is configured to allow controlled communication between different VLANs.

### DHCP

DHCP is configured to automatically assign IP addresses to client devices.

### Network Security

ACLs and Port Security are implemented to restrict unauthorized access and protect network resources.

### Secure Management

SSH is configured for secure remote access to network devices.

### NAT/PAT

NAT Overload allows multiple internal devices to share a public IP address for external communication.

### Site-to-Site VPN

IPsec VPN provides secure communication between different network locations.

### WLAN

Wireless connectivity is configured for hospital users and devices.
